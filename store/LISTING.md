Spaces Plus puts your tabs in a clean vertical sidebar, sorted into spaces. Work, study and life each get their own tabs, pinned tabs, colour and icon, so you only see what you're working on.

WHY SPACES+

★ Any width. The floating sidebar goes from a 48 px icon strip up to 520 px. Drag its edge. Most sidebars can't go thinner than Chrome's 320 px side panel.

SPACES
• Each space is a Chrome tab group with its own name, colour and emoji icon
• 9 colours plus any custom colour
• Switch with the space bar at the bottom, ⌘1–9 (Ctrl+1–9), Alt+Shift+← / →, or a two-finger sideways swipe
• Other spaces go to sleep when you switch, so Chrome uses less memory
• New tabs go into the space you're in
• Rename, recolour, reorder and delete spaces

FAVORITES AND PINNED TABS
• Favorites: a grid of your everyday sites, shared by all spaces

COMMAND BAR

NEVER LOSE TABS

## Privacy tab

**Single purpose:**
Spaces Plus organizes the user's tabs in a vertical sidebar with spaces (tab groups), favorites, pinned tabs and split view.

**Permission justifications:**

| Permission | Justification |
|---|---|
| tabs | Show the user's open tabs in the sidebar (title, address, icon) and switch, move, close and create tabs when the user asks. |
| tabGroups | Each space is a Chrome tab group. Needed to create, name, colour, collapse and switch groups. |
| sidePanel | The sidebar can open in Chrome's side panel. |
| bookmarks | Favorites and pinned tabs are stored as bookmarks in a "Spaces Plus" folder so they persist and sync. The command bar also searches bookmarks. |
| storage | Saves the user's spaces, settings and a local backup of open tabs on the device. |
| favicon | Shows site icons next to tabs, favorites and pinned tabs. |
| search | When the user types words (not an address) in the command bar, runs the search with the user's default search engine. |
| sessions | The Library's "Archived Tabs" lists recently closed tabs and lets the user reopen them. |
| downloads | The Library's "Downloads" lists the user's downloads with search. |
| downloads.open | Opens a downloaded file when the user clicks it in the Library. |
| system.display | Places the floating sidebar window on the correct screen edge so it is never off-screen. |

**Remote code:** No, I am not using remote code.
